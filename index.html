01 Selected projects

Custom CUDA Kernels for PyTorch

CSE 520 · group project

Wrote CUDA kernels for Linear Forward (matrix multiply + bias) and ReLU Backward, wired them into PyTorch through C++ torch::Tensor wrappers and Python bindings, and validated them by training an MNIST network end to end. The final part optimized and benchmarked both kernels on NVIDIA A100 GPUs against cuBLAS and PyTorch baselines.

  • Mapped CUDA threads to tensor elements, set grid/block launch configuration, and worked directly with GPU memory layout
  • Bridged Python → PyTorch/C++ → CUDA for the forward and backward passes
  • Ran on ASU's Sol HPC cluster

CUDA · C++ · PyTorch · Python · NVIDIA A100 · Linux HPC
